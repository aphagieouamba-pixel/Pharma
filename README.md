# PharmaFlow

Application de gestion de pharmacie développée en C# WPF.

## Fonctionnalités

- Tableau de bord
- Gestion des produits
- Vente et panier
- Gestion du stock et réceptions
- Inventaire
- Rapports de ventes
- Sauvegarde locale des données

## Exécution

Ouvrir `Pharmacie.Wpf/Pharmacie.Wpf.csproj` avec Visual Studio ou exécuter :

```powershell
dotnet run --project .\Pharmacie.Wpf\Pharmacie.Wpf.csproj
```
